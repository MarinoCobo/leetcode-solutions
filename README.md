# LeetCode Solutions

My daily LeetCode practice in C++. Each problem lives in its own folder with the
solution and my notes on the idea and its complexity.

```
<difficulty>/<number>_<Name>/
├── solution.cpp       # the accepted solution
└── instructions.md    # link, idea, time/space complexity, notes
```

New problems are scaffolded with `./new_problems.sh <difficulty>/<number>_<Name>`.
